# Lớp học Ô Li

Ứng dụng web học tập cho học sinh THCS: trường học nhập vai, phòng thí nghiệm ảo 3D, lớp học bảng xanh, nhiệm vụ chấm tự động, Rung chuông vàng, câu lạc bộ cờ vua và trang quản lý cho giáo viên.

- Giao diện: một trang HTML/JavaScript (`index.html`), chạy trên GitHub Pages.
- Dữ liệu: Supabase (PostgreSQL + phân quyền theo dòng). Các tệp cài đặt cơ sở dữ liệu nằm trong thư mục `supabase/`.
